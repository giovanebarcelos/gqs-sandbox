# Aula 01B — Modelos para o agente de IA

Arquivos-modelo da **Aula 01B (IA Assistida na Qualidade de Software)**. Copie para a **raiz** do repositório do seu projeto:

| Arquivo | Para quê | Slide da Aula 01B |
|---|---|---|
| `opencode.json` | Modelo gratuito (`:free`) e permissões: comandos com `ask`, `git push` negado. **Nunca** coloque a chave de API aqui | 14 e 31 |
| `AGENTS.md` | Memória do projeto para o agente: caminhos e regras, curto. Cresce a cada unidade | 33 |

Confira a configuração com `opencode debug config`. A chave da OpenRouter fica em `~/.local/share/opencode/auth.json`, fora do Git.
