# Casos de Teste — CaronaCampus (versão Java)

> 16 casos (a rubrica exige no mínimo 15). Cada caso aponta o **requisito** que cobre e a **técnica** de projeto usada (Aulas 06, 08, 09 e 10). Todos terminam em um **resultado esperado** verificável. A coluna "Automação" é conferida por `scripts/matriz_rastreabilidade.py` (opcional: precisa de Python 3 na máquina).
>
> Convenção: "agora" = 10/11/2026 12:00:00 nos testes automatizados (relógio fixo). Usuários: Ana (motorista, id 1), Bruno (id 2), Carla (id 3).
